# Como Contribuir

Este projeto segue o fluxo baseado em Issues e Pull Requests:

1. **Abra uma Issue** descrevendo a funcionalidade (`feat`) ou correção (`fix`) antes de escrever código.
2. **Crie uma Branch** vinculada à Issue (ex: `1-nome-da-tarefa`).
3. **Envie um Pull Request** para a branch `main` referenciando a Issue na descrição (`Closes #numero-da-issue`).
4. Aguarde a verificação antes de concluir o merge.
